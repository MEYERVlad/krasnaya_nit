# Заметки для разработки

Сюжет, персонажи и прохождение — в README.md. Общение с автором — на русском.

## Устройство index.html

- Всё в одном файле: CSS, SVG-defs (`#gdefs`), JS в одном IIFE.
- Сцена — SVG 1000×640. Каждая сцена — функция, возвращающая строку разметки: `room`, `boardArt`, `clockView`, `trunkView`, `renderDinner`, `bagView`, `watchView`. Таблицы `SCENES`, `PARENT` (куда ведёт стрелка «назад»), `MEMORY` (сцены в сепии).
- Кликабельные зоны — невидимые `hs(id, x, y, w, h)` / `hse(...)` поверх рисунка, обработка в `act(id, sel)` по ключу `сцена:id`. `sel` — выбранный предмет; если `act` вернул false при выбранном предмете, выполняется действие по умолчанию.
- Персонажи рисуются функцией `bust(p, opts)` из описаний в `PEOPLE`. Предметы — `ITEMS` + `icon(id)` (SVG 64×64).
- Состояние `S = {scene, inv, sel, f:{флаги}}`, сохраняется в localStorage после каждого действия. Подсказки ворона — `hint()` по флагам.
- Звук — объект `A`, эффекты `sfx.*`, музыка `music.waltz()`. AudioContext создаётся по кнопке «Начать».
- CSS для размеров SVG только через дочерние селекторы (`#scene>svg`): вложенные `<svg>` (миниатюра доски, фото на доске) иначе растягиваются.

## Проверка

Прогон всей главы через Playwright (Chromium установлен в окружении): кликать по `[data-h="..."]` и `.slot[data-i="..."]`, следить за ошибками консоли.
