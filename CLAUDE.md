# Заметки для разработки

Сюжет, персонажи и прохождение — в README.md. Общение с автором — на русском.

## Устройство index.html

- Всё в одном файле: CSS, SVG-defs (`#gdefs`), JS в одном IIFE.
- Сцена — SVG 1000×640. Каждая сцена — функция, возвращающая строку разметки. Глава I: `room`, `boardArt`, `clockView`, `trunkView`, `renderDinner`, `bagView`, `watchView`. Глава II: `newsroom(y53)` (редакция 1975 / воспоминание 1953), `cabinetView`, `darkroomView`, `rookBoard`; кадры плёнки — `printArt(n)` (viewBox 300×200). Глава III: `dorm(y31)` (спальня приюта 1975 / воспоминание 1931), `office3View`, `trayView`, `lockerView`. Таблицы `SCENES`, `PARENT` (куда ведёт стрелка «назад»), `MEMORY` (сцены в сепии), `INDOOR` (без окон: нет молний, тише дождь).
- Главы: `CHAPTERS` (ключ сохранения, названия), `S.ch` — номер главы, `fresh(n)` — начальное состояние, `switchChapter(n)`. Действия глав II и III — в `act2`/`act3`, подсказки — в `hint2`/`hint3`. Глава открывается, когда в сохранении предыдущей стоит `f.ended` (`unlocked(n)`).
- Красный свет в лаборатории — CSS-фильтр `#scene.red>svg`; цвета крышек при красном свете подменяются и в самой разметке.
- Кликабельные зоны — невидимые `hs(id, x, y, w, h)` / `hse(...)` поверх рисунка, обработка в `act(id, sel)` по ключу `сцена:id`. `sel` — выбранный предмет; если `act` вернул false при выбранном предмете, выполняется действие по умолчанию.
- Персонажи рисуются функцией `bust(p, opts)` из описаний в `PEOPLE`. Предметы — `ITEMS` + `icon(id)` (SVG 64×64).
- Состояние `S = {ch, scene, inv, sel, f:{флаги}}`, сохраняется в localStorage после каждого действия (отдельный ключ на главу). Подсказки ворона — `hint()` по флагам.
- Звук — объект `A`, эффекты `sfx.*`, музыка `music.waltz()`. AudioContext создаётся по кнопке «Начать».
- CSS для размеров SVG только через дочерние селекторы (`#scene>svg`): вложенные `<svg>` (миниатюра доски, фото на доске) иначе растягиваются.

## Проверка

Прогон всей главы через Playwright (Chromium установлен в окружении): кликать по `[data-h="..."]` и `.slot[data-i="..."]`, следить за ошибками консоли. Повторный клик по уже выбранному предмету открывает его осмотр, а не снимает выбор. Чтобы сразу попасть в главу II, положите в localStorage сохранение главы I с `f.ended=1` (или `krasnaya-nit-last=2`); для главы III — то же с главой II.
