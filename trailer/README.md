# Тизер «Красной нити»

Видео на 72 секунды про всю игру, все четыре главы. 1920×1080, 30 кадров в секунду, H.264 и AAC — подходит для Steam, RuStore, VK и YouTube.

Как он устроен:
- `scripts/plates.mjs` снимает чистые кадры сцен из игры в высоком разрешении (около 2900×1850), без интерфейса → `plates/`.
- `timeline.js` — раскадровка: какие сцены, проезды камеры, тексты, вспышки, звуковые события.
- `teaser.html` — «монтажный стол». Поверх кадров кладёт кинообработку: свечение, глубину резкости по краям, цветокоррекцию, дождь, мерцание свечей, пыль, плёночное зерно, широкоэкранные полосы, ворона и анимированный логотип с красной нитью.
- `scripts/audio.py` синтезирует звук: «Вальс для Элеоноры» на музыкальной шкатулке (со струнными и басом ближе к финалу), дождь, гром, часы, фотовспышки, машинку под текст, сердцебиение и ворона.
- `scripts/render.mjs` покадрово снимает `teaser.html` и собирает видео через ffmpeg.

## Собрать заново

Нужны Node.js 22, Python 3 с numpy, ffmpeg и Playwright с Chromium.

```
cd steam && npm run prepare-app && cd ..   # свежая копия игры с локальными шрифтами
cd trailer
node scripts/plates.mjs                    # кадры сцен
node scripts/render.mjs 10 30 61           # (по желанию) пробные кадры на 10, 30 и 61 секунде → out/preview-*.jpg
node scripts/render.mjs                    # полный рендер → out/krasnaya-nit-teaser.mp4
```

Чтобы поменять тексты, порядок сцен или длительность, правьте `timeline.js`. Звук подстраивается автоматически.
