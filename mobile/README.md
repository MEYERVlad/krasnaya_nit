# «Красная нить» для Android (RuStore)

Android-версия на Capacitor. Игра — тот же `../index.html`. Скрипт `prepare` копирует его в `www/` и подключает шрифты из `../steam/fonts`, поэтому интернет игре не нужен. В игре только горизонтальный экран и полноэкранный режим, кнопка «Назад» Android закрывает окна и возвращает на предыдущую сцену, сохранения хранятся на телефоне.

```
mobile/
  capacitor.config.json   id приложения ru.krasnayanit.game, название «Красная нить»
  android/                проект Android (Gradle)
  scripts/prepare.mjs     index.html → www/ с локальными шрифтами
  scripts/icons.mjs       значки и заставка Android из ../steam/build/icon.svg
  scripts/store-assets.mjs  скриншоты 1920×1080 для RuStore → store/screenshots
  store/                  значок 512×512 и скриншоты для страницы в RuStore
  privacy-policy.md       политика конфиденциальности
```

## Сборка

Собирает GitHub Actions (`.github/workflows/android.yml`) при каждом изменении игры или папки `mobile/`. Запустить вручную: вкладка **Actions** → **Android (RuStore)** → **Run workflow**.

Готовые файлы — на странице запуска, внизу, в блоке **Artifacts**:
- `krasnaya-nit-debug` — APK для проверки на своём телефоне;
- `krasnaya-nit-release-rustore` — подписанный APK для RuStore. Появляется только после того, как в репозиторий добавлены секреты подписи.

### Ключ подписи

Каждое обновление в RuStore нужно подписывать одним и тем же ключом. Ключ хранится вне репозитория, в секретах GitHub (**Settings → Secrets and variables → Actions**):

| Секрет | Что это |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | файл ключа `.keystore`, закодированный в base64 |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | имя ключа |
| `ANDROID_KEY_PASSWORD` | пароль ключа |

Сохраните файл ключа и пароль в надёжном месте. Если ключ потерять, выпустить обновление в RuStore будет нельзя.

### Сборка на своём компьютере (по желанию)

Нужны Node.js 22, JDK 21 и Android Studio (или Android SDK 36).

```
cd mobile
npm install
npm run sync                    # копирует свежий index.html в Android-проект
cd android && ./gradlew assembleDebug
```

## Публикация в RuStore

1. Зарегистрироваться в RuStore Консоли (console.rustore.ru) как физлицо или самозанятый. Для бесплатной игры регистрация бесплатна.
2. **Создать приложение**: тип — игра, название «Красная нить», пакет `ru.krasnayanit.game`.
3. Загрузить `app-release.apk` из артефакта `krasnaya-nit-release-rustore`.
4. Заполнить карточку:
   - **значок** — `store/icon_512.png`;
   - **скриншоты** — `store/screenshots/*.png` (1920×1080, горизонтальные);
   - **категория** — Игры → Головоломки (или Приключения);
   - **возрастной рейтинг** — 16+: в сюжете есть убийство, отравление и тема похищения детей;
   - **цена** — бесплатно;
   - **политика конфиденциальности** — ссылка на `privacy-policy.md` в репозитории (см. ниже).
5. Отправить на модерацию. Обычно её проходят за 1–3 рабочих дня.

**Краткое описание** (до 80 знаков):

> Детективная головоломка: распутайте красную нить одного ужина 1953 года.

**Полное описание:**

> 14 ноября 1953 года. Особняк мистера Пикмана. Без двадцати десять журналистка Элеонора Лэнг падает лицом в скатерть. Врач говорит: «сердце». Её семилетняя дочь видит всё из-под стола.
>
> 1975 год. Ада выросла. На её пробковой доске — лица гостей того вечера, соединённые красными нитями.
>
> • Четыре главы: особняк, редакция газеты с фотолабораторией, заброшенный приют, повторный ужин.
> • Входите в старые фотографии и разгадывайте прошлое изнутри воспоминаний.
> • Проявляйте плёнку при красном свете, подбирайте шифры, раскладывайте улики и предъявляйте их подозреваемым.
> • Рисованная графика, дождь, вальс из музыкальной шкатулки — и ворон, который знает больше, чем говорит.
>
> Без рекламы и встроенных покупок. Работает без интернета.

`https://github.com/MEYERVlad/krasnaya_nit/blob/main/mobile/privacy-policy.md`
Она заработает, когда изменения попадут в ветку `main`.

## Обновление игры

1. Изменить `index.html`.
2. GitHub Actions соберёт новый APK. Номер сборки (`versionCode`) растёт сам — это номер запуска сборки.
3. В RuStore Консоли: **Версии → Новая версия** → загрузить новый `app-release.apk`.
